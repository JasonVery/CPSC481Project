Additional Information:

For the book search feature, you dont type anything-- when you hit the search button on any page the keybaord will popup and a list of results, to simulate you searching for the words "One Thousand." You can either select any of the books on the page with the keyboard to view their specefic details, or you can click the keyboard to simulate hitting "enter/search" in order to get the the results page.

Hitting the "login" button on the navigation bar allows you to login as our demo user Ann. This will give you the ability to place books on hold, book a private room, as well as view current holds.
